GET /saju?birth=1995-03-15&time=14&gender=M
→ { "year_pillar": "을해", "month_pillar": "신묘", ... }

왜 깃허브에서 주목받기 좋냐면
이유설명희소성Python으로 된 만세력 엔진 오픈소스가 거의 없음도메인 난이도절기 기반 월 계산, 음력 변환 등 알고리즘이 까다로움한국 특화한국어 README + 한국 도메인 = 틈새시장확장성나중에 LLM 연동해서 사주 해석까지 붙이기 좋음
